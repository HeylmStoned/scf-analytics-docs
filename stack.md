# Plain-English stack

Umami, forked, serves the script, the web dashboard, and the per-project login. A small OpenTelemetry collector next to it turns API telemetry into hourly counts and latency histograms, and deletes the traces. Both write through **Redis** into **Supabase Postgres in Frankfurt**. Row-level security is per tenant. Cloudflare serves the version-pinned script and terminates TLS. Docker Compose (app + collector + Redis + Postgres) is how someone else runs it after handover. Stellar shows up in enrollment (`stellar.toml` or a contract id) and in the path normalizer (`G…`, `C…`, and `M…` addresses), not as a place we write analytics to.
