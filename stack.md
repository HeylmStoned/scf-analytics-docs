# Plain-English stack

Umami, forked, serves the script, the web dashboard, and the per-project login. A small OpenTelemetry collector next to it turns API telemetry into hourly counts and latency histograms, and deletes the traces. Validated web events and normalised API batches are admitted through Cloudflare Queues (durable), then written to Supabase Postgres. We keep one Supabase project per EU residency region (Frankfurt or London at launch); the tenant picks a region at enroll and is routed there. Row-level security is per tenant inside that project. Cloudflare also serves the version-pinned script and terminates TLS. Docker Compose is how someone else runs it after handover. Stellar shows up in enrollment (`stellar.toml` or a contract id) and in the path normalizer (`G…`, `C…`, and `M…` addresses), not as a place we write analytics to.
